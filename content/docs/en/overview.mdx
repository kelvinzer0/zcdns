# DNS Overview

The Domain Name System (DNS) is a system that translates human-readable domain names (like example.com) into IP addresses that computers can understand.

## What is DNS?

DNS functions like the internet's phone book. When you type a website name in your browser, DNS looks up the IP address that corresponds to that domain name.

## Why is DNS Important?

- **Ease of Use**: It's easier to remember "google.com" than "142.250.190.78"
- **Flexibility**: Allows server changes without changing the domain name
- **Scalability**: Supports billions of domain names worldwide

## Key DNS Components

1. **Domain Name**: Human-readable name (example: example.com)
2. **DNS Records**: Data that stores information about the domain
3. **Name Servers**: Servers that store and manage DNS records
4. **Resolvers**: Systems that translate domain names into IP addresses

DNS is the foundation of the modern internet that allows us to access websites easily using memorable names.
