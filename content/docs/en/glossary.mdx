# DNS Glossary

Collection of definitions for important terms commonly used in DNS.

## A

**A Record**
DNS record that points a domain name to an IPv4 address.

**Authoritative Nameserver**
DNS server that has definitive information about a domain.

## C

**CNAME Record**
DNS record that creates an alias or alternative name for another domain.

**Cache**
Temporary storage of DNS query results to speed up subsequent access.

## D

**DNS Propagation**
Process of spreading DNS changes to all DNS servers across the internet.

**Domain Name**
Human-readable name to identify internet addresses (example: example.com).

## F

**FQDN (Fully Qualified Domain Name)**
Complete domain name that specifies exact location in DNS hierarchy.

## M

**MX Record**
DNS record that specifies email server to receive email for a domain.

## N

**Nameserver**
Server that stores and manages DNS records for domains.

**NS Record**
DNS record that specifies which nameservers are authoritative for a domain.

## R

**Recursive Resolver**
DNS server that performs complete queries to resolve domain names.

**Root Domain**
Highest level in DNS hierarchy, represented by a dot (.).

## T

**TTL (Time To Live)**
Time in seconds that determines how long DNS records are stored in cache.

**TLD (Top-Level Domain)**
Top-level domains like .com, .org, .id in DNS hierarchy.

## Z

**Zone File**
File containing DNS records for a specific domain.
