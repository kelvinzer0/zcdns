# Glosarium DNS

Kumpulan definisi istilah-istilah penting yang sering digunakan dalam DNS.

## A

**A Record**
DNS record yang mengarahkan nama domain ke alamat IPv4.

**Authoritative Nameserver**
Server DNS yang memiliki informasi definitif tentang suatu domain.

## C

**CNAME Record**
DNS record yang membuat alias atau nama alternatif untuk domain lain.

**Cache**
Penyimpanan sementara hasil query DNS untuk mempercepat akses selanjutnya.

## D

**DNS Propagation**
Proses penyebaran perubahan DNS ke seluruh server DNS di internet.

**Domain Name**
Nama yang mudah diingat untuk mengidentifikasi alamat internet (contoh: example.com).

## F

**FQDN (Fully Qualified Domain Name)**
Nama domain lengkap yang menentukan lokasi tepat dalam hierarki DNS.

## M

**MX Record**
DNS record yang menentukan server email untuk menerima email domain.

## N

**Nameserver**
Server yang menyimpan dan mengelola DNS records untuk domain.

**NS Record**
DNS record yang menentukan nameserver mana yang authoritative untuk domain.

## R

**Recursive Resolver**
Server DNS yang melakukan query lengkap untuk menyelesaikan nama domain.

**Root Domain**
Tingkat tertinggi dalam hierarki DNS, direpresentasikan dengan titik (.).

## T

**TTL (Time To Live)**
Waktu dalam detik yang menentukan berapa lama DNS record disimpan dalam cache.

**TLD (Top-Level Domain)**
Domain tingkat atas seperti .com, .org, .id dalam hierarki DNS.

## Z

**Zone File**
File yang berisi DNS records untuk domain tertentu.
