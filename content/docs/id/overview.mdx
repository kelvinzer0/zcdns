# Pengantar DNS

Domain Name System (DNS) adalah sistem yang menerjemahkan nama domain yang mudah diingat (seperti example.com) menjadi alamat IP yang dapat dipahami oleh komputer.

## Apa itu DNS?

DNS berfungsi seperti buku telepon internet. Ketika Anda mengetik nama website di browser, DNS akan mencari alamat IP yang sesuai dengan nama domain tersebut.

## Mengapa DNS Penting?

- **Kemudahan Penggunaan**: Lebih mudah mengingat "google.com" daripada "142.250.190.78"
- **Fleksibilitas**: Memungkinkan perubahan server tanpa mengubah nama domain
- **Skalabilitas**: Mendukung miliaran nama domain di seluruh dunia

## Komponen Utama DNS

1. **Domain Name**: Nama yang mudah diingat (contoh: example.com)
2. **DNS Records**: Data yang menyimpan informasi tentang domain
3. **Name Servers**: Server yang menyimpan dan mengelola DNS records
4. **Resolvers**: Sistem yang menerjemahkan nama domain menjadi alamat IP

DNS adalah fondasi dari internet modern yang memungkinkan kita mengakses website dengan mudah menggunakan nama yang dapat diingat.
